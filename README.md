# Student Management System

A C# console application for managing students and their academic grades.

## Features

- Add students with name, age, and grade validation
- Display all students
- Search for students by name
- Display promoted students sorted by grade
- Calculate the average grade
- Find students with the highest and lowest grades
- Interactive console menu

## Technologies

- C#
- .NET 10
- Object-Oriented Programming (OOP)
- LINQ

## Concepts Practiced

- Classes, objects, and constructors
- Encapsulation and inheritance
- Polymorphism using `virtual` and `override`
- Static methods
- Collections and LINQ queries
- Input validation using `TryParse()`
- Namespaces and code refactoring

## How to Run

**Requirements:** .NET 10 SDK

1. Clone the repository.
2. Open the project folder in a terminal.
3. Run:

```bash
dotnet run
```
